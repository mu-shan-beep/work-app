# 个人工作台 1.1 · 设置、图标与发布前验收

## 如何查看

打开项目根目录 `个人工作台.app`，从「个人工作台 → 设置…」或 `Command+,` 打开；工作台内「我的 → App 设置」也有入口。当前工作台页面设计保持原样。

图标现已使用你提供的蓝色文件夹插画，原图保存在 `desktop/Workbench.png`，网页副本在 `00-入口/assets/app-icon.png`。构建优先从 PNG 生成多尺寸 icns，原先的 `Icon.swift` 仅作缺图时备用。页面左上角、程序坞和设置窗口使用同一图标。

## 设置项

| 分类 | 可配置内容 | 生效方式 |
| --- | --- | --- |
| 通用 | 登录 Mac 后自启 | 默认关闭；SMAppService 读写系统登录项，必要时由用户在系统设置批准 |
| 通用 | 默认打开工作、今日、生活或上次页面 | 下次打开 App 生效 |
| 通用 | 关闭主窗口时退出或继续运行 | 即时生效；继续运行时可通过程序坞重新打开 |
| 通用 | 记住窗口、菜单栏入口 | 窗口记忆在下次启动使用；菜单栏入口即时生效 |
| 外观 | 85%、100%、110%、125% 界面大小 | 即时生效 |
| 外观 | 减少动画、显示装饰 | 即时生效，系统减少动态效果继续受尊重 |
| 数据 | 打开目录、选择已有数据目录 | 选择时验证三个 JSON 文件，重启后切换，不迁移或覆盖原文件 |
| 数据 | 完整 JSON 备份 | 用户选择保存位置；包含任务、生活记录、分组、移除记录，不包含关联原文件 |
| 关于 | 版本、平台、更新方式 | 当前为手动更新 |

偏好设置与任务 JSON 分开保存。未擅自开启自启，也没有添加系统守护进程。

## 已验证与边界

在临时数据和独立偏好域中验证：配置跨重启持久化、原生设置四个导航入口、菜单栏对象、备份内容与三个源文件逐项一致、真实网页常用任务操作与退出前保存。真实数据哈希在相应回归测试前后一致。

自启状态通过系统 API 实时读取；自动测试不注册登录项，不替用户批准系统设置，也不重启 Mac。实际登录后的启动行为仍需你手动开启、系统允许后验收。建议先把应用放进「应用程序」并从 Finder 打开，再设置自启。当前使用本机临时签名，公开分发仍建议正式签名与 Apple 公证。
